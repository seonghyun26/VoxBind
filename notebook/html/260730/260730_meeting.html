Interpretation and leakage control.
  • Nesso-1 performs well for binding-affinity prediction (Pearson r 0.670, Spearman ρ 0.663, RMSE 1.410). However, all complexes in our lp_edrscc_v2 test set are reported as overlapping Nesso-1's affinity-training sources, so its result is a leaked upper bound rather than a clean generalization result.
  • Yes—we tested a deliberately leaked CDG probe. With the same frozen Pareto CDG encoder, the clean probe gives Pearson r 0.663, Spearman ρ 0.644, and RMSE 1.334. Appending all 1,320 test features and affinity labels to probe training (--leak_test append; 3,850 → 5,170 training examples), then evaluating on those same test examples, improves this to r 0.713, ρ 0.687, and RMSE 1.273.

It is therefore an optimistic upper bound—useful for comparison with Nesso-1's overlap, but not a clean generalization result.

2Evaluation pipeline adjusted — cropped input, whole-receptor Vina

The protein representation now has an explicit stage-specific contract. VoxBind generation remains conditioned on the local CrossDocked *_pocket10.pdb crop, because that is the model’s trained input. Primary affinity evaluation instead uses the coordinate-aligned whole receptor (*_rec.pdb) while keeping the search box on the same reference-ligand site. This prevents a cropped scoring receptor from being mistaken for the full docking environment.

A.1A concrete pocket-exclusion standard

Outlier detection is based only on the redocked reference ligand’s Vina score-only value, which diagnoses pocket/receptor preparation before any generated molecule is inspected. We use the conventional one-sided modified Z-score cutoff of 3.5, together with a positive-energy gate. This is resistant to the extreme value it is designed to detect because both its center and scale use medians. The values below document the current pocket10 audit; apply the identical rule to whole-receptor reference scores before freezing the primary evaluation mask.

Reference-only robust rule

Mi = 0.6745 · (si − median(s)) / MAD(s) Exclude when Mi > 3.5 AND si > 0 kcal/mol
  1. Score the crystallographic reference pose once with the same receptor and Vina score_only setup used by every run.
  2. Estimate center and scale across pockets: median = −5.94 and MAD = 2.31 kcal/mol for the 79-pocket density subset.
  3. Apply the dual gate. Require both a robust upper-tail outlier and a physically unfavorable positive score. Here the robust condition is stricter, so the rule is equivalent to reference score > +6.05 kcal/mol.
  4. Freeze the resulting pocket mask and apply it unchanged to the reference and every generated method. Do not remove individual generated molecules.

Reporting specification.
  • Primary estimand: equal-weight mean across the 77 retained pockets, after computing each pocket’s metric from its valid generated molecules.
  • Success rate: for each pocket, compute mean(QED > 0.25 AND SA > 0.59 AND Vina Dock < −8.18) over molecules with all three finite values, then average the pocket rates equally across the QC 77 set. The inequalities are strict, matching DecompDiff.

5Uncertainty & readout — beyond a plain MLP probe

Inspired by TerraBind, whose affinity module reads binding strength from a rich pair / distogram representation through a pairformer and adds an epinet for calibrated affinity uncertainty. Our winning champion probes affinity far more simply: it mean-pools all patch tokens of the frozen C+D+G encoder into one 640-D vector and regresses with a 2-layer MLP — a strong point estimate, but a blended average with no interaction structure and no uncertainty. This section tests richer readouts on the same frozen champion (100M · v2 · mask0.75; no re-pretraining): split the tokens into ligand-region vs pocket-region pools by input occupancy, and make affinity an explicit ligand×pocket interaction (TerraBind's pair-rep idea), plus an epinet uncertainty head. All rows share the identical frozen features, split (lp_edrscc_v2, 3850/817/1320), and 3-seed protocol; only the head differs.

Result: the interaction heads do not beat mean-pool — the caveat won. Binding affinity is fundamentally a ligand–pocket interaction, so we made it explicit; but on 3,850 labels the richer heads lose monotonically with head size: mean-pool ρ 0.641 > split-pool 0.634 > bilinear 0.625. The most-parameterized head (bilinear) is worst and its validation ρ also drops (0.527) — the overfitting signature we predicted (TerraBind trains its pairformer on millions of labels; we have 3,850, and attention-pool < mean-pool + fine-tune-hurt already showed high-capacity heads overfit here). Mean-pool's simplicity wins. Cross-attention (C, even more parameters) is therefore deprioritized; the remaining value is the epinet head (D) for calibrated uncertainty — not to raise ρ, but to give a per-ligand affinity σ for de novo screening, which the plain MLP cannot.
Uncertainty result: it does not calibrate on the frozen probe — a fundamental negative, not a tuning miss. All three methods — TerraBind-style epinet, gold-standard deep ensemble (10 bootstrap members), and MC-dropout — preserve the point estimate (ρ 0.64) but produce σ that does not track error: corr(σ, |err|) = −0.03 / −0.11 / −0.01, and selective RMSE rises when keeping the most-confident predictions (deep ensemble 1.388 → 1.410 → 1.453 at all / conf-50% / conf-25%). Because even the deep ensemble — the most reliable epistemic method, with real σ ≈ 0.34 pK — fails, this is fundamental: the frozen-probe errors are representation-limited, not epistemic. The 3,850 points densely cover the feature space, so the ensemble is ~equally confident everywhere; the ~0.64 ceiling means certain complexes are simply not predictable from the frozen features, and that missing-information error is invisible to ensemble disagreement. Implication: TerraBind-style calibrated uncertainty needs end-to-end training on ∼10⁶ affinity labels plus a structural (distogram-entropy) signal — neither available to the frozen density probe. Uncertainty is not a free add-on here.
Method & verdict.
  • Frozen, shared features: every head reads the identical 100M v2 mask0.75 encoder; per-patch tokens are soft-pooled into ligand-region (g_lig) and pocket-region (g_poc) vectors by input occupancy (ligand channels 0–6, pocket 7–10). No encoder retraining (test/head_designs.py).
  • Pipeline validated: the matched-protocol mean-pool reproduces the canonical champion (ρ 0.641 vs 0.644) — so the head deltas are trustworthy. (Matched-protocol RMSE 1.420 differs from the canonical 1.349 only because the head-sweep MLP uses its own fixed hyper-parameters across all rows; the comparison is apples-to-apples.)
  • Interaction bias does not transfer at this label count: mean 0.641 → concat 0.634 (−0.007) → bilinear 0.625 (−0.016); more head capacity = worse test ρ. A·concat's better val (0.563) and RMSE (1.391) but worse test ρ is a mild-overfit tell, not a win.
  • Uncertainty is the portable win: the epinet head (D) gives a calibrated per-ligand affinity σ for ranking / triage in de novo screening — the capability the plain MLP cannot provide — regardless of point-estimate ρ. This is the one TerraBind ingredient worth carrying over.
