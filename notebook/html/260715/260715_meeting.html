1 Binding-affinity regression — four test cases

Frozen-probe binding-affinity (pK) regression on LP-PDBBind ∩ ED+RSCC, Kd/Ki split (lp_edrscc_v2, 3850 / 817 / 1320, 3 seeds), for the density encoder C + D + G (coords + density + gradmag, ChannelViT [7,4,2]). The core is the 2×2 factorial of encoder size ∈ {40M, ~98M} × pretraining corpus ∈ {PLINDER v1 (17.5K), PLINDER v2 (110K)}, plus a depth-scaled variant (dim 512×24, ~85M) that reaches large capacity by stacking layers instead of widening — a direct width-vs-depth control against the ~98M dim-768 model. All cells are now filled. The clean read: the 6.4× corpus regresses the frozen probe at both sizes (40M 0.637 → 0.620, ~98M 0.626 → 0.595), and within v2 smaller > depth > width (0.620 > 0.608 > 0.595). The single best cell stays 40M·v1 ρ 0.637 — neither more data nor more parameters (via width or depth) breaks the ceiling.

  • The four test cases = C + D + G ChannelViT [7,4,2] × {40M, ~98M} × {PLINDER v1, v2}, same lp_edrscc_v2 Kd/Ki probe (n_test = 1,320, 3 seeds).
  • PLINDER v1 (filled from 260701). Size scaling on v1 has already turned over: 40M reaches test ρ 0.637 (the headline C+D+G number), but the dim-768 ~98M regresses to ρ 0.626 — the curve has plateaued / regressed in this data-limited regime.
  • PLINDER v2 — ~98M (done). The per-element C+D+G ~98M encoder was re-pretrained at 110K (100 ep, 112,000 crops) and lands at test ρ 0.595 ± 0.002 (r 0.613, RMSE 1.511). The 6.4× corpus did not help the big model — it hurt: the same dim-768 encoder went 0.626 (v1) → 0.595 (v2), −0.031. Reconstruction improved with more data (val L_dens 0.0027) but the pooled affinity feature did not — consistent with a representation/probe-data ceiling, not a data-starvation one (the role-split encoder was likewise a wash at 110K: ρ 0.585 → 0.577).
  • PLINDER v2 — depth beats width (done). At matched large capacity on the same 112,000 crops, the depth-scaled ~85M (dim 512×24) reaches ρ 0.608 ± 0.001 — +0.013 over the width-based ~98M (dim 768×12, ρ 0.595), with markedly better calibration (RMSE 1.393 vs 1.511). So stacking layers scales better than widening here. But depth still does not break the ceiling: 0.608 < the 40M·v1 plateau (0.637) and the ~98M·v1 (0.626) — more data + more depth helps the axis choice, not the overall level.
  • PLINDER v2 — 40M base (done): more data hurts the small model too. The 40M on v2 lands at ρ 0.620 ± 0.001 — −0.017 below its v1 self (0.637). So the 6.4× corpus regresses the frozen probe at both sizes (40M −0.017, ~98M −0.031), the drop growing with capacity. Within v2, the 40M is nonetheless the best cell (0.620 > depth 0.608 > width 0.595) — smaller wins on the larger corpus, consistent with a capacity-and-data ceiling rather than a data-starvation one. (eff-batch 120 on 3 GPUs after a host-OOM relaunch; the ±0.06 RMSE reflects one higher-variance seed.)
  • Bottom line. Best overall = 40M·v1 ρ 0.637. Neither scaling data (v1→v2, regresses at both sizes) nor scaling parameters — whether by width (dim768, 0.626/0.595) or depth (dim512×24, 0.608) — breaks the ~0.63 frozen-probe ceiling. Depth is the better capacity axis (+0.013 vs width) but not a way through it.
