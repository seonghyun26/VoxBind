4 Architecture ablation: ViT vs Channel-ViT

Why this ablation: every input channel we add (atom, density, gradmag — and more to come) is concatenated into the standard ViT's single shared patch projection, so heterogeneous channels (binary atom occupancy vs continuous density / gradmag fields) compete for the same weights; Channel-ViT instead tokenizes each channel separately and fuses them with cross-channel attention, which should scale better as the channel stack grows.

Atom types are wildly imbalanced in the voxel grid — carbon fills orders of magnitude more atom-on voxels than rare types (S, P, halogens), so an unweighted reconstruction loss is dominated by the common atoms. The pretraining loss can rebalance this with a per-channel weight w = (1/freq)p: uniform (p = 0, no rebalancing), inv-sqrt-freq (p = 0.5, gentle), inv-freq (p = 1, rare atoms much heavier). This ablation asks whether that choice changes the frozen affinity probe.
