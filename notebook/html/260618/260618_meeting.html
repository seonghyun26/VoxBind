So VoxBind's advantage is its pretrained, frozen 40M encoder (only a ~66K MLP head sees labels), not raw capacity: matched at 40M params, the from-scratch supervised model is far worse.

  • Noise control overturns the “density helps” story. Replacing the density+gradmag slots with matched random noise (real coords kept, noise at both pretrain and probe via --noise_voxels_dir) gives test ρ 0.609 ± 0.002 — it matches/exceeds the real density+gradmag encoder (0.595, same learnable PE) and sits +0.065 above coords-only (0.544). So the celebrated “+0.05 ρ from density” is reproduced by noise: on top of atom coordinates the gain is added-channel capacity, not density information. Noise is i.i.d. random, fixed per complex, with zero affinity content, so it cannot be leaking signal — the lift comes from the wider input / MAE-pretraining task, not the values.
  • Zero control clinches it — it's the architecture, not the channel content. Density+gradmag zero-filled at both pretrain and probe still gives test ρ 0.599 ± 0.000 — on par with noise (0.609) and real (0.595). So it isn't even that a varying channel helps: the entire +0.05 over coords-only is the wider 13-channel encoder / MAE objective, independent of what the density slots contain (zero ≈ noise ≈ real >> coords-only 0.544). Zero control = 260613_…_zerocontrol.
  • The fields do carry real signal — but it is redundant with coordinates. With no atom channels, gradmag-only (test ρ 0.551) and density-only (0.505) both land far above chance — a noise-only single channel would be ~0, so the electron-density and its gradient field genuinely encode affinity. Notably gradmag-only > density-only (0.551 vs 0.505) and nearly ties coords-only (0.544): the edge/surface field ‖∇ρ‖ is the strongest single channel. Yet the noise control shows this signal is already captured by the atom coordinates — it adds nothing unique once coords are present.
  • Gradmag is still redundant on top of density. Pure density-only (0.505) exactly matches density+gradmag only (0.505): stacking ‖∇ρ‖ onto density buys nothing. (Encoders: learnable PE, same 2172/480/839 split. Noise control = 260612_…_noisecontrol; gradmag-only = 260612_gradmagonly_density_xray_vit_mae_40m_v5.)

3 Architecture ablation: ViT vs Channel-ViT

Why this ablation: every input channel we add (atom, density, gradmag — and more to come) is concatenated into the standard ViT's single shared patch projection, so heterogeneous channels (binary atom occupancy vs continuous density / gradmag fields) compete for the same weights; Channel-ViT instead tokenizes each channel separately and fuses them with cross-channel attention, which should scale better as the channel stack grows.

Atom types are wildly imbalanced in the voxel grid — carbon fills orders of magnitude more atom-on voxels than rare types (S, P, halogens), so an unweighted reconstruction loss is dominated by the common atoms. The pretraining loss can rebalance this with a per-channel weight w = (1/freq)p: uniform (p = 0, no rebalancing), inv-sqrt-freq (p = 0.5, gentle), inv-freq (p = 1, rare atoms much heavier). This ablation asks whether that choice changes the frozen affinity probe.
