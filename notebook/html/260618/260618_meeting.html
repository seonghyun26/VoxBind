Table 5  ·  Architecture ablation — ViT vs Channel-ViT vs ChA-MAEViT (affinity)

Same frozen-probe affinity task and input (coordinates + density + gradmag) as Table 1, varying only the encoder architecture. The standard ViT stacks all input channels at the patch embedding, so heterogeneous channels (binary atom occupancy vs continuous density / gradmag fields) compete for one shared projection; Channel-ViT tokenizes each channel separately and fuses them with cross-channel attention; ChA-MAEViT adds memory tokens, dynamic channel-patch masking, and a Fourier recon term (arXiv:2503.19331). Canonical LP-PDBBind split (n = 2172/480/839); learnable PE; mean ± std over 3 seeds. The ViT row is Table 1's PLINDER inv-freq combined encoder (test ρ 0.624) and remains best: Channel-ViT ties it within seed noise (0.618, −0.006) and ChA-MAEViT is modestly worse (0.602, −0.022).

  • Why this ablation. Every input channel we add (atom, density, gradmag — and more to come) is concatenated into the standard ViT's single shared patch projection, so heterogeneous channels compete for the same weights. Channel-ViT tokenizes each channel separately and fuses them with cross-channel attention, which should scale better as the channel stack grows; ChA-MAEViT stacks the MAE pretraining tricks on top.
  • Result: the plain ViT wins. On the large, clean PLINDER C+D+G corpus the fused ViT (test ρ 0.624) edges out Channel-ViT (0.618, −0.006 — a tie within seed noise) and clearly beats ChA-MAEViT (0.602, −0.022, with a higher RMSE 1.483). Channel tokenization buys nothing here. Notably this reverses the small-corpus CrossDocked v5 result where ChA-MAEViT was the best encoder (0.613 vs fused 0.595): channel-aware fusion helps when density data is scarce/noisy, but the fused ViT scales better once the corpus is large and ligand-matched. All three share identical input, data, split and learnable PE, so the gap is architecture-only.

Atom types are wildly imbalanced in the voxel grid — carbon fills orders of magnitude more atom-on voxels than rare types (S, P, halogens), so an unweighted reconstruction loss is dominated by the common atoms. The pretraining loss can rebalance this with a per-channel weight w = (1/freq)p: uniform (p = 0, no rebalancing), inv-sqrt-freq (p = 0.5, gentle), inv-freq (p = 1, rare atoms much heavier). This ablation asks whether that choice changes the frozen affinity probe.
