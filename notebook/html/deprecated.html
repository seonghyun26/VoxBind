Table 1b  ·  Single-channel input ablation (affinity)

Single-channel affinity probes on the current LP-PDBBind split (n = 2172/480/839; ViT / learnable-PE encoder; mean ± std over 3 seeds). The three ref rows are the on-split encoder baselines (identical to Table 1's affinity rows). Density-only and gradmag-only isolate each single field; the noise control (real coords + matched random-noise density+gradmag) tests whether density's gain is real signal or added capacity — it is capacity (noise 0.609 ≥ real 0.595, see notes).   • Noise control overturns the “density helps” story. Replacing the density+gradmag slots with matched random noise (real coords kept, noise at both pretrain and probe via --noise_voxels_dir) gives test ρ 0.609 ± 0.002 — it matches/exceeds the real density+gradmag encoder (0.595, same learnable PE) and sits +0.065 above coords-only (0.544). So the celebrated “+0.05 ρ from density” is reproduced by noise: on top of atom coordinates the gain is added-channel capacity, not density information. Noise is i.i.d. random, fixed per complex, with zero affinity content, so it cannot be leaking signal — the lift comes from the wider input / MAE-pretraining task, not the values.
  • Zero control clinches it — it's the architecture, not the channel content. Density+gradmag zero-filled at both pretrain and probe still gives test ρ 0.599 ± 0.000 — on par with noise (0.609) and real (0.595). So it isn't even that a varying channel helps: the entire +0.05 over coords-only is the wider 13-channel encoder / MAE objective, independent of what the density slots contain (zero ≈ noise ≈ real >> coords-only 0.544). Zero control = 260613_…_zerocontrol.
  • The fields do carry real signal — but it is redundant with coordinates. With no atom channels, gradmag-only (test ρ 0.551) and density-only (0.505) both land far above chance — a noise-only single channel would be ~0, so the electron-density and its gradient field genuinely encode affinity. Notably gradmag-only > density-only (0.551 vs 0.505) and nearly ties coords-only (0.544): the edge/surface field ‖∇ρ‖ is the strongest single channel. Yet the noise control shows this signal is already captured by the atom coordinates — it adds nothing unique once coords are present.
  • Gradmag is still redundant on top of density. Pure density-only (0.505) exactly matches density+gradmag only (0.505): stacking ‖∇ρ‖ onto density buys nothing. (Encoders: learnable PE, same 2172/480/839 split. Noise control = 260612_…_noisecontrol; gradmag-only = 260612_gradmagonly_density_xray_vit_mae_40m_v5.)
