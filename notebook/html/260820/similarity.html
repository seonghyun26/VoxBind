2실험 설계

모든 representation은 공통 complex와 공통 pair에서 비교했다. Encoder 추출과 pair 분석은 GPU 없이 CPU에서 수행했다.

Representation similarity

각 feature dimension을 전체 공통 cohort에서 표준화한 뒤 cosine similarity를 계산했다. Raw cosine, centered cosine, z-scored distance도 sensitivity metric으로 함께 보존했다.

Full protein sequence

Bundled CPU MMseqs2, minimum identity 0.20, bidirectional coverage 0.80. 본문 correlation은 MMseqs homolog pair에서 계산했다.

Pocket sequence

구조 기반 pocket mask로 residue를 선택하고 parent-sequence 순서로 연결했다. BLOSUM62 global alignment, gap-open −10, gap-extension −0.5의 aligned identity를 사용했다.

Ligand and affinity

Ligand는 Morgan radius 2 / 2,048-bit Tanimoto, affinity 변화는 |ΔpK|로 정의했다. Near-ligand subset은 Tanimoto ≥ 0.8이다.

6해석, 한계, 다음 단계

  • 초기 가설은 지지된다. Similar sequence, 특히 similar pocket sequence는 similar encoded representation과 일관되게 연결된다.
  • Pocket은 전체 sequence보다 직접적인 축이다. 동일 homolog subset에서 모든 모델의 pocket ρ가 full-sequence ρ보다 높다.
  • Affinity training이 cliff-aware geometry를 보장하지는 않는다. CheapNet과 GET은 pocket homology를 강하게 보존하지만 cliff AUC는 각각 0.551, 0.583이다.
  • 표현의 목적이 서로 다를 수 있다. 높은 homology correlation은 좋은 retrieval/cluster geometry를 뜻할 수 있지만, binding-affinity 변화에 필요한 국소 interaction signal과는 동일하지 않다.

Caveats

  • Pocket residue는 공간적으로 선택된 불연속 residue를 parent-sequence 순서로 연결한 것이다. 따라서 일반적인 contiguous domain sequence identity와 동일하지 않다.
  • Pair들이 protein family와 PDB complex를 공유하므로 서로 독립적인 관측치가 아니다. 현재 SEM과 correlation은 family-level uncertainty를 반영하지 않는다.
  • GET affinity head는 variable-length block representation에 작용한다. 비교에는 모델의 native fixed-width graph_repr를 사용했으므로 정확한 pre-head sufficient statistic은 아니다.
  • Feature standardization은 전체 분석 cohort에서 수행한 descriptive analysis다. 별도의 predictive test metric으로 해석하면 안 된다.

Recommended follow-ups

  1. Partial correlation. Full-sequence identity와 ligand Tanimoto를 통제한 뒤 pocket identity가 representation similarity를 추가로 설명하는지 측정한다.
  2. Family-block bootstrap. MMseqs cluster 단위로 bootstrap해 ρ와 cliff AUC의 confidence interval을 구한다.
  3. Local representation comparison. GET block states, attention-pooled pocket states, VoxBind spatial token을 직접 비교해 global pooling에서 희석되는 cliff signal을 찾는다.
  4. Retrieval evaluation. Representation nearest neighbors가 same pocket family, same ligand scaffold, 또는 similar pK를 얼마나 회수하는지 Recall@k / enrichment로 평가한다.
