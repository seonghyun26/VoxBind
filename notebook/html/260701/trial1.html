VoxBind · autoresearch · dramatic change #1

Trial 1 — Contiguous cluster masking

masking algorithmnew code opt-in, non-destructive · base = ChannelViT [7,4,2] (ρ≈0.637) · done — ρ 0.609 (−0.028)

Hypothesis

The campaign showed two things about masking: (1) easier/more-local masking hurts — finer blocks (block 4) collapsed to 0.583, and lowering the ratio (mask 0.4) lost ground; (2) only atom-targeted masking (atom-bias) ever helped. Both point the same way: the encoder learns better when forced to infer missing structure from long-range context, not fill small local gaps.

Standard block masking drops many small, scattered blocks (≈50% of the volume in 2 Å cubes). This trial takes the lesson to its logical end: mask a few LARGE contiguous regions, centred on the atoms, so the model must reconstruct whole chemical substructures from their surroundings — the image-MAE regime (large masked spans → semantic features), but anchored to chemistry rather than random.

What was implemented

A new masking function make_cluster_mask in models/mae_ops.py, plus a new opt-in strategy mae.mask_strategy=cluster wired through the train + val mask paths in train_density.py. Fully non-destructive: uniform stays the default; uniform/atom_biased code is untouched; the only new config key is mae.mask_n_seeds (default 4).

Algorithm — per sample, at block resolution (gb³ blocks):

  • sample n_seeds seed blocks, weighted by atom mass (∝ avg_pool3d of the atom channels — like atom-bias picks atom-rich regions);
  • compute each block's Euclidean distance to its nearest seed;
  • mask the floor(ratio·gb³) blocks closest to any seed → exactly ratio coverage, as n_seeds large contiguous clusters;
  • upsample the block mask back to voxels.
# models/mae_ops.py — core of make_cluster_mask(atoms_sum, block_size, ratio, n_seeds=4)
w = (F.avg_pool3d(atoms_sum, block_size) * block_size**3).reshape(B, n_blocks).clamp_min(0) + 1e-6
coords = stack(meshgrid(arange(gb), arange(gb), arange(gb))).reshape(-1, 3).float()
for b in range(B):
    seeds = multinomial(w[b], n_seeds)              # atom-weighted seed blocks
    dist  = cdist(coords, coords[seeds]).amin(dim=1) # nearest-seed distance
    mask[b, dist.topk(n_mask, largest=False).indices] = True  # closest n_mask blocks

Enable: mae.mask_strategy=cluster +mae.mask_n_seeds=4  ·  default n_seeds=4 → ~4 large holes covering 50%; n_seeds=1 → one big ball.

Smoke verification (CPU)

  • exact mask fraction = 0.500 (target 0.5); shape/dtype correct;
  • contiguous — masked-block spread ≈ 3.2 (clustered, not scattered);
  • atom-anchored — atom mass inside the mask ≫ outside (≈ 7.0 vs 1.4);
  • deterministic given a generator seed; uniform & atom_biased outputs unchanged (no regression).

Result & interpretation

Cluster masking HURT — ρ 0.609, a robust −0.028 (±.001, well outside the ~±0.02 seed noise). The "large contiguous masks → semantic features" intuition from image-MAE does not transfer to this domain.

Reason: atom/density signal is sparse and local, not redundant like image pixels. Masking a few large contiguous chunks centred on the atoms removes most of the irreplaceable local signal at once, so the reconstruction target is unrecoverable rather than usefully hard.
