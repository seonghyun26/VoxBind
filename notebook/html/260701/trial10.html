Trial 10 — data2vec latent-target MAE

NLP/CV transfer (data2vec)SSL targetnew code base = ChannelViT [7,4,2] (ρ≈0.637) · done — ρ 0.621 (−0.016, slight hurt)

Hypothesis

Our MAE reconstructs raw voxels — it may over-invest in low-level density texture rather than affinity-relevant structure. data2vec (Baevski 2022, the same recipe works across speech / vision / text) instead regresses the EMA-teacher's contextualized latent features at masked positions — a semantic, self-distilled target. If the plateau is partly a target-quality limit (raw voxels too low-level), a latent target should learn a better representation. Unlike the InfoNCE trial (which failed — instance discrimination is anti-affinity), this is a per-position regression to the teacher latent, not a contrastive objective.

What was implemented

Opt-in mae.data2vec_weight (default 0). The EMA teacher (already maintained for checkpoints) sees the FULL input → per-patch pooled latent, LayerNorm'd = the target. The student sees the masked input → a predictor head maps its pooled patches → predicts the teacher latent at masked patches (smooth-L1), added to the MAE loss. Predictor is pretrain-only (not in encoder.*) → frozen probe bit-exact.

# train_density.py — hybrid: MAE recon + data2vec latent distillation
target = EMA_teacher.pool(forward_features(x_full))      # (B,N,D), LayerNorm, no-grad
pred   = student.predictor(student.pool(forward_features(x_masked)))
L = L_mae + 0.1 * smoothL1(pred[masked_patches], target[masked_patches])

Enable: +mae.data2vec_weight=0.1 (hybrid; weight balances L_mae≈0.065 vs L_d2v≈0.37). Smoke: teacher target LayerNorm'd, masked-patch loss finite, grads reach predictor+encoder, predictor excluded from encoder.* (probe strict-load OK), full-pipeline L_d2v 0.37 alongside L_dens 0.065, no unused params.

data2vec did not help — it slightly hurt (ρ 0.621). The signature matches the other aux objectives that regressed: validation dropped (best_val 0.51 vs 0.53) and the frozen probe early-stopped at epoch 29–38 (vs ~100), i.e. the features are genuinely a bit worse, with worse RMSE (1.416 vs 1.353). The latent-distillation target didn't beat raw-voxel reconstruction here. Together with trial 9, both cross-domain SSL tricks land at-or-below the plateau (stochastic depth 0.630 tie, data2vec 0.621 hurt) — adding a co-objective or a semantic target doesn't lift the representation ceiling any more than the masking/pretext variants did.
