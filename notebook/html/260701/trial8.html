VoxBind · autoresearch · dramatic change #8

Trial 8 — Distance-conditioned atom embedding

representationuser ideanew code base = ChannelViT [7,4,2] · radius-embed k=8 · done — ρ 0.574 (HURT, −0.040 vs k=8)

Hypothesis

The radius-embed (trial 7) deposits one learned vector per atom, scaled by a fixed Gaussian falloff — the embedding's radial profile is not learned. Here the profile itself becomes learnable: the embedding near an atom is a learned mixture of Gaussians at multiple widths, so the model can shape core-vs-shell structure. Tests whether a richer spatial profile (vs trial-7-k8's richer channels, which hurt) helps.

What was implemented

Extended RadiusAtomEmbed with scales=[σ_b] (model-only, chosen over a heavier per-voxel-MLP splat). φ now outputs B·k; for each scale the occupancy is depthwise-blurred by σ_b and contracted with that scale's weights, then summed — a learned radial profile as a mixture of Gaussian widths. scales=[0.0] == the trial-7 single-scale version exactly (backward-compat verified).

# models/density_vit.py — RadiusAtomEmbed, scales=[0,2,4] voxels
e = Σ_b  W[:,b,:] · blur_{σ_b}(occupancy)     # W = φ(radius) → (elem, B, k)

Enable: +model.radius_embed_k=8 +model.radius_embed_scales=[0.0,2.0,4.0]. Caveat: blur only widens the already-broad σ≈6.8-vox blob (can't sharpen the core), and broad scales leak some neighbor density across mask boundaries (base scale exact). Smoke: backward-compat, blur spreads, φ grads, probe-parity strict.

Distance-conditioning HURT. The learned multi-scale radial profile made the representation worse than the single fixed-Gaussian k=4 (0.624) and even k=8 (0.613). The caveat played out: the broad-scale blurs (a) only widen the already-smeared σ≈6.8-vox blob and (b) leak neighbor density across mask-block boundaries, easing the MAE task → weaker features. The fixed Gaussian splat was not leaving anything on the table; a richer spatial profile via blur-mixture is counterproductive. Single-scale radius-embed k=4 stays the family best. Folded into Phase 8.
