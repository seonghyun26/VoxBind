VoxBind · autoresearch · dramatic change #4

Trial 4 — Interface masking (binding contact)

masking algorithmon-themenew code base = ChannelViT [7,4,2] (ρ≈0.637) · done — ρ 0.610 (−0.027)

Hypothesis

Binding affinity is determined at the ligand–pocket interface — the contact region where atoms of the two molecules pack against each other. Trial 3 masks the ligand; this one masks the contact itself. If the encoder must reconstruct the interface from its surroundings, it should learn the interaction geometry (complementarity, packing) that affinity actually depends on — arguably the single most affinity-relevant region a self-supervised objective could target.

What was implemented

A new opt-in mae.mask_strategy=interface backed by make_interface_mask in models/mae_ops.py. Each block is scored by ligand×pocket co-occupancy (block-level occupancy of each, dilated by one block so adjacency — not overlap — counts); the top ratio·gb³ blocks (the contact) are masked. Non-destructive: default uniform unchanged; ligand/cluster/atom-bias untouched.

# models/mae_ops.py — make_interface_mask(lig_sum, poc_sum, block_size, ratio, tau=0)
lb = max_pool3d(avg_pool3d(lig_sum, block), 3, 1, 1)   # dilated ligand occupancy (block-res)
pb = max_pool3d(avg_pool3d(poc_sum, block), 3, 1, 1)   # dilated pocket occupancy
score = lb * pb                                        # high only where BOTH present nearby = interface
mask  = topk(score, n_mask)                            # mask the contact blocks

Enable: mae.mask_strategy=interface mae.mask_ratio=0.3 mae.mask_atom_tau=0.0. Smoke: masks the lig–poc contact (1.00) while ignoring an isolated pocket lump (0.00).

Result & interpretation

Interface masking HURT — ρ 0.610, a robust −0.027. With trial 3 (ligand, −0.016) this completes a clear verdict: every targeted/concentrated masking hurts — cluster (−0.028), interface (−0.027), ligand (−0.016) — while uniform scattered masking is optimal (0.637).

Even masking exactly where binding happens makes the representation worse. Concentrating the mask on one region removes too much local signal there and over-specialises the reconstruction, whereas broad scattered masking forces general, distributed feature learning. Masking strategy is not the lever. Folded into Phase 8.
