VoxBind · autoresearch · dramatic change #3

Trial 3 — Ligand masking (pocket → ligand)

masking algorithmon-themenew code base = ChannelViT [7,4,2] (ρ≈0.637) · done — ρ 0.621 (−0.016)

Hypothesis

The previous masking trials hid random or atom-rich regions. This one masks something specific and meaningful: the ligand. If the encoder is forced to reconstruct the ligand region from the surrounding pocket, it has to learn which ligands a pocket admits — exactly the de-novo placement problem VoxBind is built for. Those pocket-conditioned, binding-aware features are plausibly the most affinity-relevant signal a self-supervised objective could produce here.

What was implemented

A new opt-in mae.mask_strategy=ligand in the MAE prefetcher (train_density.py). It masks the blocks most occupied by ligand atoms — reusing the existing atom-biased top-K selector, but weighted by the ligand mass only (v_lig.sum) instead of all atoms. The masked region (across all input channels) covers the ligand and its immediate surroundings; the encoder reconstructs it from the rest (mostly pocket). Non-destructive: default uniform unchanged; atom_biased/cluster untouched; no new mask function (reuses make_atom_biased_block_mask).

# train_density.py — mask_strategy == "ligand":
lig_sum = v_lig.sum(dim=1, keepdim=True)            # ligand-only occupancy (7 lig channels)
mask = make_atom_biased_block_mask(lig_sum, block_size, ratio, tau)  # top-K ligand-mass blocks
# mask ≈ ligand footprint → reconstruct ligand region from the pocket

Enable: mae.mask_strategy=ligand mae.mask_ratio=0.25 mae.mask_atom_tau=0.5  ·  small ratio (≈ ligand footprint) + low tau (strong ligand focus) so the masked region is the ligand, not half the pocket.

Result & interpretation

Ligand masking HURT — ρ 0.621, a robust −0.016 (±.002). The most on-theme idea did not produce better affinity features.

The likely reason is a task mismatch: reconstructing the ligand from the pocket is a generative objective — "what could bind here" — which is underdetermined (many ligands fit a pocket) and trains features for placement. The frozen probe asks a discriminative question — "how tightly does this ligand bind". Features optimised for generation aren't the features that rank affinity, so the pretext pulls the representation the wrong way. (Smaller mask ratio also gives less of the standard MAE signal.)
