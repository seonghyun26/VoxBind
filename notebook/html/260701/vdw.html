van der Waals atom blobs — diameter, σ, and voxel profile

How an atom becomes a voxel blob

Each atom is rendered into the voxel grid as an isotropic Gaussian bump (voxelizer.py): peak 1.0 at the atom center, decaying with distance. The width is set by the element's van der Waals radius — in the role-split representation, atom identity is carried entirely by this blob size, not by a one-hot channel.

w(d) = exp( −d² / 2σ² ) σ = radius / resolution  (voxels) resolution = 0.25 Å · grid 64³ · so σvox = r × 4, and σ in Å equals r

Blob value vs. distance from center

Gaussian profile for each atom type. Every heavy element is drawn (faint grey); nine representatives spanning the size range are highlighted. The dashed line marks w = 0.607, which every curve crosses at exactly d = σ (= vdW radius) — so the coloured dots read off each atom's radius on the x-axis.

x in Å (voxel equivalents below, ×4) · 1 voxel = 0.25 Å · diverse range r 1.47–3.43 Å (σ 5.9–13.7 vox).

  • The organic atoms overlap. C/N/O/S sit at r 1.52–1.80 Å (σ 6.1–7.2 vox): their curves differ by < 1 voxel in width — a sub-voxel, smooth, peripheral difference the masked-reconstruction loss barely penalises. Distinguishing them by blob size alone is hard.
  • The diverse atoms separate clearly. Metals/heavy main-group sit at σ ≈ 8–9 vox and the alkali metals (K/Rb/Cs) reach σ 11–14 vox — visibly wider blobs whose size is recoverable. This is why admitting them lifts the role-split probe (0.554 → 0.585 ρ), but they are too rare to fix the dominant C/N/O/S sub-voxel ambiguity.
  • The peak is always 1.0 regardless of element — the radius changes only the width, never the height.
