Trial 9 — Stochastic Depth (DropPath)

CV transfer (DeiT/MAE)regularizernew code base = ChannelViT [7,4,2] (ρ≈0.637) · done — ρ 0.630 (tie, −0.007)

Hypothesis

The campaign's single most robust finding is that capacity / overfitting hurts the frozen probe (dim768 −0.011, finetune −0.032, radius-embed k=8 < k=4). Stochastic Depth (Huang 2016; standard in DeiT & MAE) is the canonical ViT regularizer for exactly that failure mode — it randomly drops whole residual branches during training, forcing the network to not over-rely on any one layer. If the plateau is an overfitting ceiling, this is the most likely single knob to lift it.

What was implemented

A DropPath module + opt-in model.drop_path (default 0 → bit-identical). Per sample, each block's attn and MLP residual branches are dropped with prob p (survivors rescaled 1/(1−p)); p ramps linearly 0→drop_path across depth (DeiT schedule). No parameters, eval = identity → frozen probe + checkpoints bit-exact; drops activations not weights → DDP-safe.

# models/density_vit.py — TransformerBlock
x = x + drop_path(attn(norm1(x)))
x = x + drop_path(mlp(norm2(x)))      # p ramps 0→0.1 over the 12 blocks

Enable: +model.drop_path=0.1 · controlled change off [7,4,2], only this knob. Smoke: per-block ramp 0→0.1, train stochastic, eval deterministic, drop_path=0 encoder loads strict (0 new params).

Stochastic depth ties the base — no lift. ρ 0.630 sits within the ±0.02 pretrain-seed floor of [7,4,2] (whose two-seed mean was 0.633), and RMSE is unchanged (1.390 ≈ 1.353). So the canonical overfitting regularizer does not move the plateau — even though overfitting is the campaign's clearest failure mode (capacity/finetune both hurt), adding stochastic regularization neither helps nor hurts. This sharpens the diagnosis: the ceiling isn't an over-fitting gap a regularizer can close, it's a representation/probe-data ceiling. Folded into Phase 8.
