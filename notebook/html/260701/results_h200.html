Reading it

The clean comparison is the first table: same 112k complexes, same density boxes, same C+D+G ChannelViT — only the atom channels change. Going from 2 role-occupancy channels (roleblob) to 8 element channels (atomblob8) adds +0.065 ρ. The v2.1 row (atomblob7) drops the 8th "other" channel and excludes the complexes whose ligand needed it, isolating how much the rare out-of-vocab atoms contribute vs. a clean 7-element vocabulary. The v2.1 predict-density row asks a different question — make density a decoder-only target (atoms in, ρ+∇ρ reconstructed) rather than an input channel: it reaches 0.607, just below the 0.617 of feeding density in, so the encoder learns density structure well from atoms alone, but a direct density input is marginally better.

Cross-set rows (coords+density / density-only on the 17k _v2clean set) are shown for reference only — they are not on the same pretraining corpus as the 112k rows.
