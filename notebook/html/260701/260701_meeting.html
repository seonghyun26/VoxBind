ProFSA (ICLR 2024; frozen self-supervised pocket encoder + probe) is the strongest structural baseline here at ρ 0.597 / r 0.626, just above GET (ICML 2024, E(3)-equivariant, trained on split; ρ 0.591 / r 0.596) — both still below the frozen C+D+G density probe (ρ 0.637). DSMBind (NeurIPS 2023, unsupervised energy, zero-shot) ranks at ρ 0.363 but that is essentially a molecular-size artifact (size-partialled ρ 0.168). Putting it on the same footing as the other probes — freezing its SE(3)-DSM encoder, mean-pooling per-atom features, and fitting a 3-seed MLP head on lp_edrscc_v2 — lifts it to ρ 0.507 ± 0.010 / r 0.541 / RMSE 1.494 (now in pK units). The trained head more than doubles the size-independent signal (partial ρ 0.168 → 0.394), but ~a quarter of the headline 0.507 is still ligand size (pred ↔ n_atoms ρ 0.589), so it stays the weakest structural baseline on ranking. BindNet (ICLR 2024) has no public code.
  • Why the DSMBind zero-shot row is a single value (no ±SD). (The probe row above does carry ±SD — its MLP head is fit over 3 seeds like every other trained row.) Every trained/fit row on lp_edrscc_v2 is run over 3 seeds (random init + stochastic optimization) and reported as mean ± SD. The zero-shot DSMBind energy score is deterministic — a frozen, pretrained SE(3)-DSM energy function scores each complex deterministically (same weights, same inputs → identical prediction), so there is nothing for seeds to vary; a "3-seed" run would just repeat ρ 0.363 with ±0.000. Its RMSE is n/a because the model emits an uncalibrated energy score (not pKd/pKi units): ranking metrics (Spearman ρ, and the size-partialled ρ 0.168 that is the real story) apply, but absolute error does not. An honest uncertainty band for it would come from bootstrap resampling the test set, not seed averaging.
  • AEV-PLIG (Valsson et al., Comms Chem 2025) — architecture only (GATv2 over a ligand graph whose nodes carry radial Atomic-Environment-Vectors of the protein pocket; their BindingNet/BindingDB data-augmentation dropped).
  • AEV-PLIG scaling 7.55M → 40M (hidden 256→512, 5→8 GNN layers) regresses: per-seed ρ 0.492→0.472, ensemble ρ 0.550→0.537, RMSE 1.480→1.512. Naive parameter scaling hurts in this data-limited regime (3.8k train) — consistent with HBGSA-40M (ρ 0.533→0.372) and the dim-768 ChannelViT encoder.
  • Boltz and ESM embedding baselines are placeholders — values pending.
  • Not benchmarked here (no public weights / proprietary): Boltz-2 (Wohlwend et al. 2025) co-folds structure + affinity but its affinity head targets within-series ranking and likely overlaps PDBbind (leakage); TerraBind (Terray Therapeutics, arXiv 2602.07735, 2026) reports SOTA affinity (~20% > Boltz-2, 26× faster via a coarse Cβ + ligand-heavy-atom representation with COATI-3 + ESM-2 encoders) but is a proprietary EMMI-Predict product with no released weights. Both are cited as references, not table rows.

2 Diverse atom types

A diverse-atom-type (role-split) representation admits the full element set by carrying atom identity in blob size (vdW radius) instead of per-element channels. Table 3 compares it to the canonical per-element encoder, and asks whether scaling the PLINDER corpus 6.4× (v1 17.5K → v2 110K) closes the gap. The v2 corpus selection funnel is in Appendix A.

Table 3  ·  Diverse atom types (role-split representation)

Instead of per-element one-hot channels (canonical reduced element set), the role-split representation uses a small set of role channels [ligand, pocket] in which atom identity is carried by blob size (per-atom vdW radius) rather than a one-hot channel — so the full / diverse element set is admitted. Two corpus sizes test whether more data closes the gap to per-element: v1 (17,530) and v2 (110K, App. A) — both C + D + G ChannelViT, OTF, frozen probe on lp_edrscc_v2 (3 seeds). Reference row = the canonical per-element C + D + G ChannelViT from Table 1.

4 Density: input vs. reconstruction target

§1 showed the density-input encoder (C+D+G) beats coords-only (C) by +0.032 ρ (0.637 vs 0.605). But is that gain because the encoder sees the electron density, or because its self-supervised objective must represent it? This section isolates the two. We pretrain a coords-only encoder — fed just the 11 atom channels (ChannelViT [7,4]) — whose masked-reconstruction target still includes density + gradmag. The encoder never sees density at its input but must predict the electron-density field (+ ‖∇ρ‖) at masked voxels from atoms alone. A tie with C+D+G ⇒ the density signal is learnable from coordinates (a capacity / SSL-target effect); a tie with C ⇒ the gain genuinely needs density at the input. Same architecture & recipe as the §1 [7,4,2] winner, PLINDER v1, 100 ep. Result: ρ 0.610 — essentially tied with coords-only C (0.605), and far short of the density-input C+D+G (0.637). Reconstructing density as a pretext target does not recover the gain: the experimental-density signal has to be at the input.

5 Activity cliffs

Bulk correlation (ρ) rewards getting the overall potency range right. Activity cliffs — pairs of near-identical ligands (≥0.9 Tanimoto/scaffold/Levenshtein) with a large potency gap (|ΔpK|>1) — test whether a model captures the fine SAR that matters for lead optimisation. Headline (§5.1): our own density-backed complexes grouped by UniProt target — 113 test-test cliffs, all with experimental density (the statistically robust set; exact-sequence grouping was too strict at only 42). §5.2 shows one cliff; §5.3 cross-checks against the expert MoleculeACE benchmark filtered to density (small, n=7).

Conclusion: on a statistically meaningful cliff set (n=113), density does not resolve activity cliffs better than coords — the two are tied — and no model, supervised or not, ranks cliffs well.

  • Density ties coords. C+D+G sign-acc 0.655 ≈ C 0.646 (paired Wilcoxon p=0.37, n.s.), and C+D+G's cliff error is if anything slightly worse (RMSEcliff 1.663 vs 1.619). Density's affinity advantage (sanity ρ +0.035) lives in the bulk, not the cliffs — confirming the earlier finding on a 16×-larger set.
  • Nobody resolves cliffs. All sign-acc sit in 0.56–0.67 against a 0.50 chance floor; TargetDiff/EGNN is worst (0.558). The frozen density/coords probes have the lowest cliff error (1.62–1.66) — both supervised baselines are higher (TargetDiff 1.71, HBGSA 1.85).
  • This set supersedes the n=7 MoleculeACE result (§5.3). Grouping by UniProt target instead of exact protein sequence recovers 42→113 density-backed cliffs (exact-seq split one protein across constructs). The apparent “density wins” on the tiny expert set does not hold here. ¹ HBGSA scored on 84/113 pairs it covers.
