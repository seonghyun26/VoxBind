2 PLINDER dataset and diverse atom types

The self-supervised pretraining corpus is built from PLINDER (2024-06 / v2). §2.1 is the selection funnel from the raw annotation table down to the trained set; §2.2 probes a diverse-atom-type (role-split) representation that admits the full element set.

2.1  ·  PLINDER selection funnel

One row per physical ligand-instance (left) with the unique 4-char PDB entries it spans (right); each stage is applied on top of the previous. Source: splits/plinder/v2/plinder_funnel.json. The v2 max-coverage recipe leans on ligand RSCC ≥ 0.8 alone for density quality — no resolution cap, all PLINDER splits, multi-ligand, no dedup — growing the corpus from v1's 17,530 to 113,976 ligand-instances across 41,833 PDB entries (→ 112,733 role-split OTF training positions).

  • Table 1, Table 2 and §2.2 probe results below are still on the prior v1 corpus (17,530); the v2 (110K) encoder is pretraining now — its frozen probe will refresh those rows.

2.2  ·  Diverse atom types (role-split representation)

Instead of per-element one-hot channels (canonical reduced element set), the role-split representation uses a small set of role channels [ligand, pocket] in which atom identity is carried by blob size (per-atom vdW radius) rather than a one-hot channel — so the full / diverse element set is admitted. Pretrained on the diverse PLINDER corpus (data_train_plinder_diverse.pt, 17,530), C + D + G ChannelViT, frozen probe on lp_edrscc_v2 (3 seeds). Reference row = the canonical per-element C + D + G ChannelViT from Table 1.
