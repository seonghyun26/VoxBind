VoxBind · autoresearch · dramatic change #2

Trial 2 — Cross-modal masking

SSL objectivenew code opt-in, non-destructive · base = ChannelViT [7,4,2] (ρ≈0.637) · done — ρ 0.635 (−0.002, tie)

Hypothesis

Every trial so far masks space (which voxels to hide) and reconstructs locally. This asks a different question: instead of "fill the spatial hole", force the encoder to learn the physical map between modalities — given the atoms, predict the electron density (and ‖∇ρ‖) they produce. If the encoder has to generate the density field from atom positions, it must internalise the atoms↔density relationship, which spatial inpainting (where the density is mostly visible) never demands.

What was implemented

A new opt-in knob mae.modal_mask_prob (default 0.0 = no-op) in the MAE prefetcher (train_density.py). On top of the usual 50% spatial block mask, for each sample independently with probability p, the entire density + gradmag modality is dropped from the input (both channels zeroed everywhere) while the reconstruction target is unchanged — so the recon loss now scores an atoms → density prediction for those samples. Non-destructive: uniform/atom-bias/cluster masking and the spatial path are all untouched; p=0 reproduces the baseline exactly.

# train_density.py — after the spatial MAE mask (x_in = x_noisy * ~mask):
if modal_mask_prob > 0 and layout["n_density"] > 0:
    drop = rand(B) < modal_mask_prob               # per-sample, ~p fraction
    x_in[drop, layout["density_idx"]] = 0          # zero density channel
    x_in[drop, layout["gradmag_idx"]] = 0          # zero gradmag channel
# target (x_clean) unchanged → those samples learn atoms → density+gradmag

Enable: +mae.modal_mask_prob=0.5 (new key → Hydra +). At p=0.5, half the batch is a cross-modal density-from-atoms task; the other half is normal spatial MAE.

Smoke verification (CPU)

  • channel layout for C+D+G: n_in=13, atoms 0–10, density_idx=11, gradmag_idx=12;
  • dropped samples → density & gradmag channels all-zero; kept samples → density intact; atom channels never touched;
  • config composes with +mae.modal_mask_prob=0.5.

Result & interpretation

Cross-modal masking is a tie — ρ 0.635, within the ±0.02 seed noise of the 0.637 base. Forcing the encoder to predict density from atoms neither helps nor hurts the affinity representation.

Consistent with the campaign's broader finding that density is largely capacity-redundant for affinity: the model already sees the atoms, and learning to generate the density they produce adds no affinity-relevant signal beyond what spatial MAE already captures. A clean negative for the "learn the physics map" hypothesis — at least as measured by the frozen affinity probe. Folded into autoresearch.html Phase 8.
