⚠ The version gains are within noise — weighting matters more than the data

v5 → v6 → v7 move only 0.595 → 0.606 → 0.593 (invfreq), all inside ±0.01 seed spread. The one real swing is loss weighting: v7 recovers from 0.593 (invfreq) to 0.608 (uniform), and v6 is flat 0.606→0.608. So far, more / cleaner ligand-matched density has not decisively beaten the v5 baseline on the frozen affinity probe — PLINDER (2.2× the v7 data) is the current attempt to break that ceiling.

Normalization lineage (all in dataset/00b_density_preprocess.py, the --version branch)

  • v1 xray_crops_aligned — per-map z-score, ±3σ clip at load.
  • v2 pocket-pool z-score  x' = (x − μ)/σ crops purged
  • v3 pocket-pool symmetric  x' = x / max_abs → [−1,+1]
  • v4 pocket-pool clip+z  x' = (clip(x) − μ_c)/σ_c crops purged
  • v5 pocket-pool arcsinh+z  x' = (arcsinh(x/s) − μ_a)/σ_a — the canonical scale reused by v6 / v7 / plinder.
  • v6 = v5 norm, but availability restricted to ligand-matched poses (--native_filter tt_min).
  • v7 = built by dataset/00h_make_v7.py (unions v6 + PDBbind train); plinder by dataset/03c_plinder_preprocess.py. Both reuse the v5/v6 arcsinh+z stats.
On disk: only v3 and v5 survive at the full 78,528 crops; v2 and v4 crop dirs were purged after probing (their results below are from runs whose crops no longer exist).

⚠ Two unrelated things are both called "v4"

Density v4 = the clip+z normalization above (a crop-dir variant). "merged-density v4" = a separate dual-head encoder config (config_train_atomblob_merged_density_vit_mae_40m_weighted_v4) that regressed badly. The token "v4" is overloaded across the data axis and the model axis — see the config inventory below.

† coords-only is n_test=922, a slightly different test set than the 839-row conditions — read it as "≈0.60", not a same-set delta.

✔ Finding: the density channel buys capacity, not content

noise (0.609) ≥ zero (0.599) ≥ real (0.595), and coords-only is already ≈0.60 — replacing real electron density with noise or zeros does not hurt the affinity probe. The extra input channels add representational capacity, but the experimental density signal itself is not what drives the affinity gain. (Single-channel gradmag-only 0.551 > density-only 0.505 shows ‖∇ρ‖ does carry some real, if coords-redundant, signal.) This is the central motivation for the ligand-matched v6/v7/PLINDER line — to find a regime where real density finally beats the capacity controls.

⚠ Anomaly: ChA-MAE collapses on v6 but not v5

The v6 ChA-MAE frozen probe scored ρ = 0.130 (val loss 1.78 vs ~1.42 for the working runs) — a collapse, not a real density result. Because the v5 ChA-MAE probe worked fine (0.613), this is specific to the v6 run / its probe feature extraction (suspected n_memory_tokens wiring in the probe build), not a property of ligand-matched data. Do not report 0.130 as a v6 finding — flag for a re-probe before trusting.
