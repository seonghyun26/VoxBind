# VoxBind v4 leakage inputs

The files in this directory are frozen inputs to the v4 pocket-density corpus.
They are generated by:

```bash
python dataset/v4/leakage.py
```

`protected_pdb_ids.csv` contains every downstream PDB experiment that must not
enter a v4 training cluster:

- validation and test members of the canonical binding-affinity split
  `lp_edrscc_v2`;
- both receptor and ligand-source structures represented by the serialized
  CrossDocked2020 test tuples.

PDB protection is propagated to the complete merged pocket component. If a
component receives incompatible requests, `test > val > train`. This preserves
the downstream test boundary even when AHoJ links, alternative holo structures,
or interface-pocket unions bridge previously separate source records.

The canonical v4 pocket follows VoxBind: all protein heavy atoms whose nearest
holo-ligand heavy atom is within 10 Å. The residue/atom identity is transferred
to apo and alternate-holo partners; the experimental density always comes from
the partner structure's own deposited map.

`plinder_v3_component_audit.json` is generated with:

```bash
python dataset/v4/audit_plinder.py
```

It propagates PLINDER's seed validation/test rows and the downstream protected
PDB IDs to complete `pocket_fident__50__weak__component` components, then
asserts that train, validation, and test component sets are pairwise disjoint.

Final `manifest.parquet` and optional pair-edge tables are gated with:

```bash
python dataset/v4/acceptance.py manifest.parquet \
  --pairs pair_edges.parquet \
  --density-root dataset/data \
  --check-density-files \
  --coverage-report coverage_report.md
```

This implements the A1-A5 assertions and emits the A6 coverage report. Density
rows additionally carry `density_source_pdb_id`, `grid_frame_id`, and
`density_registration_ok`, because experimental-map provenance and local-grid
registration must be machine-checkable rather than inferred.

The official AHoJ v2c download is accepted only after:

```bash
python dataset/v4/ahoj_archive.py
```

This verifies the exact 40,181,598,291-byte archive, its MD5, the nested archive
header, and the official database statistics, then writes `ahoj_v2c.json`.
The HTTP ETag is retained separately: AHoJ serves a Starlette-style
`MD5("mtime-size")` ETag, so it must not be mistaken for the archive's
file-content MD5.

After verification, compact relation metadata can be produced without expanding
the nested archives:

```bash
python dataset/v4/ingest_ahoj.py --skip-archive-verification
```

The streaming reader retains query holo, apo, and alternative-holo rows while
leaving alignment matrices, logs, and predicted-model metadata compressed.

The completed source-ingest validations are frozen in
`ahoj_relation_ingest.json` and `plinder_apo_build.json`. They record output
hashes, exact funnels, consistency checks, and the small difference between the
published AHoJ statistics and the rows actually present in the v2c archive.
These are source-build reports, not final corpus counts: cross-source
canonicalization, the structure-factor gate, merged-component assignment, and
final density acquisition still occur before `manifest.parquet` is frozen.
